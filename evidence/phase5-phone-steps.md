# Phase 5 phone checks

Keep USB connected, unlock the Samsung phone and leave its screen on. During
automated UI tests, do not tap, swipe or use Back. No new permission is needed.
Tests use separately named synthetic databases. Never uninstall or clear storage.

## Owner readability check after automated tests

1. Open BETTER → Plan → Routines and adaptive day.
2. Tap Routines → New routine. Inspect Name, Effective date and Ordered steps.
   Tap Cancel change; this check does not save anything in your personal plan.
3. Tap Profiles → New profile → Add block. Inspect title, time, duration, priority,
   fixed checkbox and commitment links. Tap Cancel change.
4. Tap Modes and overrides → Day override. Enter reason `Preview only`.
   Leave Keep essential only checked → Preview change. Review the kept/suppressed
   items and dates. Use Next preview items if shown. Tap Cancel change.
5. Confirm the text/buttons are readable and there is no clipping or hidden action.
6. Tap Commitments, then Today. Existing Career/Rescue controls should remain.

## Optional offline review when prompted

Swipe down twice → Flight mode on → Wi-Fi off if still on. Open BETTER and repeat
the preview-only steps above. Afterwards restore Flight mode off and Wi-Fi on,
matching this session's initial state. Leave notification permission unchanged.

## Personal use after this gate

- Routines → New routine → one step per line → Preview change → Confirm adaptive
  change. Attach to a saved scheduled commitment, choose its routine and date,
  then preview and confirm. Runs and history → Open the dated routine → Complete
  or Skip each step. Leaving the page keeps the saved checklist.
- Edit a routine/profile using a later effective date; old versions remain listed.
- Profiles → New profile (or Duplicate) → Add blocks → preview → confirm.
  Assign the saved profile by weekday numbers (1=Monday, 7=Sunday) or one-off day.
- Modes and overrides → Configure a preset → dates and editable item policies →
  reason → preview. If dates overlap another mode, read the warning and explicitly
  tick Keep these overlaps; latest mode wins before confirming.
- Day override → date and reason → Keep essential only or per-item Keep/Move/Skip.
  Suppressed items carry the reason in Review. Essential health items default to
  keep; check your instructions before explicitly changing them.
